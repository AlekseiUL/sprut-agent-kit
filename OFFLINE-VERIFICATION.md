# Offline verification boundary

Repeated install preserves existing soul/config/imported memory files.

## Reproduce

`python3 -m unittest discover -s tests -v`

Dependency/daemon integrations are stubbed; tests decline optional installations. No active ClaudeClaw host or service is certified. Existing destinations must be trusted and owned by the operator.

## Rollback

Review the commit diff and use a new checkout of the pre-change commit for source rollback. Keep user data and live installations untouched. A source rollback is not permission to restore unsafe network exposure or bypass approval.
